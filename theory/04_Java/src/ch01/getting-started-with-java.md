# ✨ 자바 시작하기

## 1. 클래스명과 소스파일명

자바에서는 클래스명과 소스파일명이 같아야 한다.

즉, 파일 이름을 정할 때 클래스 이름과 정확히 일치하게 작성해야 한다.  
또한 자바는 대소문자를 구분하므로 이름을 작성할 때 주의해야 한다. ⚠️

예를 들어 클래스명이 `Hello`이면 파일명도 `Hello.java`여야 한다.

## 2. main 메소드

`main` 메소드는 자바 프로그램이 실행될 때 가장 먼저 시작되는 부분이다.

즉, `main`은 프로그램의 시작점이며 entry point라고 부른다. 📌  
자바 프로그램을 실행하면 JVM은 가장 먼저 `main` 메소드를 찾고, 그 안의 코드를 순서대로 실행한다.

## 3. 세미콜론

자바에서는 문장의 끝에 세미콜론(`;`)을 반드시 붙여야 한다.

세미콜론은 하나의 문장이 끝났음을 나타내는 표시이다.  
만약 세미콜론을 쓰지 않으면 문법 오류가 발생한다.

즉, 자바에서 세미콜론은 매우 기본적이지만 꼭 지켜야 하는 규칙이다. ✅

## 4. 중요 포인트 📌

- 클래스명과 소스파일명은 같아야 한다.
- 자바는 대소문자를 구분한다.
- `main` 메소드는 프로그램의 시작점이다.
- 문장 끝에는 세미콜론(`;`)을 반드시 붙여야 한다.

## 정리 ✅

자바를 시작할 때 가장 먼저 알아야 할 기본 규칙은 클래스명과 소스파일명이 같아야 한다는 점, 대소문자를 구분한다는 점, `main` 메소드가 프로그램의 시작점이라는 점이다.  
또한 자바의 모든 문장은 끝에 세미콜론을 붙여야 하므로 문법 작성 시 꼭 주의해야 한다.
