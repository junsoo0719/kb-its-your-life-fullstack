# ✨ 사용자 관리

## 1. 사용자 관리의 개념

MySQL에서는 데이터베이스에 접속할 사용자를 생성하고, 사용자별로 접근 권한을 부여할 수 있다.  
사용자 관리는 보안과 직접 관련되므로 일반적으로 관리자 계정인 `root` 권한으로 실행해야 한다. 📌

즉, 사용자 관리는 "누가 데이터베이스에 접속할 수 있는지"와 "무엇을 할 수 있는지"를 설정하는 작업이다.

## 2. 관리자 권한 필요

사용자를 추가하거나 삭제하고 권한을 부여하려면 관리자 권한이 필요하다.

보통 MySQL에서는 `root` 계정으로 접속한 뒤 사용자 관리 명령을 실행한다.

즉, 일반 사용자 계정으로는 다른 사용자 생성이나 권한 부여가 제한될 수 있다. ⚠️

## 3. 사용자 추가

새 사용자를 추가할 때는 `CREATE USER` 문을 사용한다.

기본 형식은 다음과 같다.

    CREATE USER '사용자명'@'호스트명' IDENTIFIED BY '비밀번호';

예를 들면 다음과 같다.

    CREATE USER 'user1'@'localhost' IDENTIFIED BY '1234';

이 구문은 `localhost`에서 접속 가능한 `user1` 사용자를 생성하고, 비밀번호를 `1234`로 설정한다.

## 4. 호스트명의 의미

MySQL 사용자 계정은 사용자명뿐만 아니라 접속 호스트명까지 함께 구분한다.

즉, 다음 두 계정은 서로 다른 계정으로 취급될 수 있다.

    'user1'@'localhost'
    'user1'@'%'

여기서 호스트명은 해당 사용자가 어느 위치에서 접속할 수 있는지를 의미한다. 📌

## 5. 접속 호스트 제한 풀기

사용자의 접속 호스트 제한을 풀고 싶다면 호스트명에 `%`를 지정한다.

    CREATE USER 'user1'@'%' IDENTIFIED BY '1234';

`%`는 모든 호스트에서 접속 가능하다는 의미로 사용된다.

즉, 특정 PC나 서버에서만 접속하게 하려면 호스트명을 제한하고, 여러 위치에서 접속 가능하게 하려면 `%`를 사용할 수 있다. ⚠️

보안상 운영 환경에서는 필요한 호스트만 허용하는 것이 더 안전하다.

## 6. 사용자 삭제

사용자를 삭제할 때는 `DROP USER` 문을 사용한다.

기본 형식은 다음과 같다.

    DROP USER '사용자명'@'호스트명';

예를 들면 다음과 같다.

    DROP USER 'user1'@'localhost';

이 구문은 `localhost`에서 접속 가능한 `user1` 계정을 삭제한다.

## 7. 권한 관리

사용자에게 데이터베이스나 테이블에 대한 권한을 부여할 때는 `GRANT` 문을 사용한다.

기본 형식은 다음과 같다.

    GRANT ALL PRIVILEGES ON 데이터베이스명.객체 TO '사용자명'@'호스트명';

예를 들면 다음과 같다.

    GRANT ALL PRIVILEGES ON employees.* TO 'user1'@'localhost';

이 구문은 `user1`에게 `employees` 데이터베이스의 모든 객체에 대한 권한을 부여한다. ✅

## 8. 데이터베이스의 모든 객체 지정

특정 데이터베이스의 모든 객체를 지정할 때는 `데이터베이스명.*` 형식을 사용한다.

    데이터베이스명.*

예를 들면 다음과 같다.

    employees.*

여기서 `*`는 해당 데이터베이스 안의 모든 테이블과 객체를 의미한다.

즉, 데이터베이스 전체에 권한을 부여하고 싶을 때 사용한다. 📌

## 9. 권한 적용

권한 변경 후 적용하려면 `FLUSH PRIVILEGES`를 실행한다.

    FLUSH PRIVILEGES;

이 명령은 권한 설정을 다시 로드해서 변경 사항이 적용되도록 한다.

권한 관련 작업 후에는 습관적으로 실행해 두면 좋다.

## 10. 사용자 관리 흐름

사용자 관리의 기본 흐름은 다음과 같다.

1. 관리자 계정으로 접속한다.
2. `CREATE USER`로 사용자를 생성한다.
3. `GRANT`로 필요한 권한을 부여한다.
4. `FLUSH PRIVILEGES`로 권한을 적용한다.
5. 필요 없어진 사용자는 `DROP USER`로 삭제한다.

즉, 사용자 생성과 권한 부여는 별개의 작업이므로 둘 다 처리해야 실제로 데이터베이스를 사용할 수 있다. ✅

## 11. 중요 포인트 📌

- 사용자 관리는 관리자 `root` 권한으로 실행해야 한다.
- 사용자 추가는 `CREATE USER`를 사용한다.
- 사용자 삭제는 `DROP USER`를 사용한다.
- MySQL 사용자는 `'사용자명'@'호스트명'` 형태로 구분된다.
- 호스트명에 `%`를 지정하면 모든 호스트에서 접속 가능하다.
- 권한 부여는 `GRANT` 문을 사용한다.
- 모든 권한 부여는 `GRANT ALL PRIVILEGES`를 사용한다.
- 특정 데이터베이스의 모든 객체는 `데이터베이스명.*`으로 지정한다.
- 권한 적용은 `FLUSH PRIVILEGES`로 처리한다.

## 정리 ✅

MySQL 사용자 관리는 데이터베이스 접속 계정을 만들고 권한을 부여하는 작업이다.  
사용자 추가는 `CREATE USER '사용자명'@'호스트명' IDENTIFIED BY '비밀번호';` 형식으로 작성하고, 삭제는 `DROP USER`를 사용한다.  
권한은 `GRANT ALL PRIVILEGES ON 데이터베이스명.객체 TO '사용자명'@'호스트명';`으로 부여하며, 데이터베이스 전체 객체는 `데이터베이스명.*`으로 지정한다.  
권한 설정 후에는 `FLUSH PRIVILEGES;`를 실행해 변경 사항을 적용한다.  
시험 대비에서는 사용자명과 호스트명을 함께 구분한다는 점, `%`의 의미, `CREATE USER`, `DROP USER`, `GRANT`, `FLUSH PRIVILEGES`의 역할을 꼭 기억해야 한다.
