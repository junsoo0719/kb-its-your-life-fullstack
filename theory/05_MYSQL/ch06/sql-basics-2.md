# ✨ SQL 기본2

## 1. 데이터 삽입 INSERT

`INSERT`는 테이블에 새로운 데이터를 삽입할 때 사용하는 SQL 문이다.

기본 형식은 다음과 같다.

    INSERT [INTO] 테이블이름 [(열이름1, 열이름2, ...)]
    VALUES (값1, 값2, ...);

`INTO`는 생략할 수 있지만, 일반적으로는 가독성을 위해 함께 작성하는 경우가 많다.

즉, `INSERT`는 테이블에 새로운 행(row)을 추가하는 명령이다. 📌

## 2. 열 이름을 지정하는 경우

삽입할 열 이름을 직접 지정하면 해당 열에 맞는 값만 넣을 수 있다.

    INSERT INTO member (id, name)
    VALUES (1, '홍길동');

이 방식은 어떤 열에 어떤 값이 들어가는지 명확하게 알 수 있어서 안전하다.

특히 일부 열만 값을 넣고 싶거나, 자동 입력되는 열이 있는 경우에는 열 이름을 명시하는 방식이 좋다. ✅

## 3. 열 이름을 생략하는 경우

테이블 이름 다음에 열 이름을 생략할 수도 있다.

    INSERT INTO member
    VALUES (1, '홍길동', '서울');

이 경우 `VALUES` 뒤에 나오는 값의 순서와 개수가 테이블 정의와 정확히 동일해야 한다.

즉, 테이블에 정의된 모든 열에 대해 순서대로 값을 넣어야 한다.  
순서나 개수가 맞지 않으면 에러가 발생할 수 있다. ⚠️

## 4. AUTO_INCREMENT

`AUTO_INCREMENT`는 숫자 값을 자동으로 증가시켜 입력하는 기능이다.

보통 기본키처럼 각 행을 구분하는 번호 컬럼에 사용한다.

특징은 다음과 같다.

- 1부터 증가하는 값이 자동 입력됨
- `INSERT` 시 해당 열은 없는 것처럼 생각하고 입력 가능
- `NULL`을 지정하면 자동으로 값이 입력됨
- `PRIMARY KEY` 또는 `UNIQUE` 컬럼에만 사용 가능
- 데이터 형식은 숫자 형식만 가능

즉, 직접 번호를 넣지 않아도 MySQL이 자동으로 고유한 숫자를 만들어 준다. 📌

## 5. AUTO_INCREMENT 사용 예시

예를 들어 `id` 컬럼이 `AUTO_INCREMENT`라면 다음처럼 입력할 수 있다.

    INSERT INTO member (name, age)
    VALUES ('홍길동', 20);

이 경우 `id`는 자동으로 증가된 값이 들어간다.

또는 `id`에 `NULL`을 넣어도 자동 증가 값이 입력된다.

    INSERT INTO member (id, name, age)
    VALUES (NULL, '홍길동', 20);

즉, 자동 증가 컬럼은 사용자가 직접 값을 관리하지 않아도 된다.

## 6. 대량의 샘플 데이터 생성

대량의 샘플 데이터를 생성할 때는 `INSERT INTO ... SELECT` 구문을 사용할 수 있다.

기본 형식은 다음과 같다.

    INSERT INTO 테이블이름 (열1, 열2, ...)
    SELECT 열1, 열2, ...
    FROM 다른테이블;

즉, 다른 테이블에서 조회한 결과를 새 테이블에 한 번에 삽입할 수 있다.

이 방식은 테스트 데이터 생성이나 테이블 간 데이터 복사에 유용하다. ✅

## 7. 데이터 수정 UPDATE

`UPDATE`는 기존 데이터를 수정할 때 사용하는 SQL 문이다.

기본 형식은 다음과 같다.

    UPDATE 테이블이름
    SET 열1 = 값1, 열2 = 값2, ...
    WHERE 조건;

즉, `WHERE` 조건에 맞는 행의 값을 `SET`에 지정한 값으로 변경한다.

## 8. UPDATE 사용 시 주의점

`UPDATE`에서 `WHERE`절은 생략할 수 있다.  
하지만 `WHERE`절을 생략하면 테이블 전체 행의 내용이 변경된다. ⚠️

예를 들어 다음 구문은 모든 행의 값을 변경할 수 있다.

    UPDATE member
    SET age = 20;

따라서 실제 데이터를 수정할 때는 반드시 `WHERE` 조건을 먼저 확인하는 습관이 필요하다.

## 9. 안전 모드

MySQL Workbench의 안전 모드에서는 키 컬럼이 아닌 컬럼을 기준으로 수정할 때 실행 에러가 발생할 수 있다.

즉, 실수로 대량 데이터를 수정하는 것을 막기 위한 보호 기능이다.

안전 모드에서는 보통 기본키나 인덱스 컬럼을 조건으로 사용하는 수정문이 더 안전하게 실행된다. 📌

## 10. 데이터 삭제 DELETE FROM

`DELETE FROM`은 테이블에서 행 단위로 데이터를 삭제할 때 사용하는 SQL 문이다.

기본 형식은 다음과 같다.

    DELETE FROM 테이블이름
    WHERE 조건;

즉, 조건에 맞는 행을 삭제한다.

## 11. DELETE 사용 시 주의점

`DELETE`에서도 `WHERE`절은 생략할 수 있다.  
하지만 `WHERE`절을 생략하면 테이블의 전체 데이터가 삭제된다. ⚠️

예를 들면 다음 구문은 모든 행을 삭제한다.

    DELETE FROM member;

따라서 `DELETE`를 실행하기 전에는 조건을 반드시 확인해야 한다.

## 12. DELETE, DROP, TRUNCATE 차이

데이터를 삭제하는 명령은 목적에 따라 구분해서 사용해야 한다.

### 12-1. DELETE

`DELETE`는 DML 문이며 행 단위로 데이터를 삭제한다.  
트랜잭션 로그 기록 작업 때문에 대량 삭제 시 느릴 수 있다.

    DELETE FROM 테이블이름
    WHERE 조건;

조건을 주어 일부 행만 삭제할 수 있다.

### 12-2. DROP

`DROP`은 테이블 자체가 더 이상 필요 없을 때 사용한다.

    DROP TABLE 테이블이름;

즉, 테이블 구조와 데이터가 모두 삭제된다.

### 12-3. TRUNCATE

`TRUNCATE`는 테이블 구조는 남겨 두고 내부 데이터만 빠르게 삭제할 때 사용한다.

    TRUNCATE TABLE 테이블이름;

DDL 문이므로 일반적으로 `DELETE`보다 빠르게 전체 데이터를 삭제할 수 있다. 📌

## 13. 삭제 명령 선택 기준

삭제 목적에 따라 적절한 명령을 선택해야 한다.

- 일부 행만 삭제 → `DELETE`
- 테이블 자체가 필요 없음 → `DROP`
- 테이블 구조는 남기고 전체 데이터만 삭제 → `TRUNCATE`

즉, 데이터만 지울 것인지, 테이블 자체를 지울 것인지에 따라 명령이 달라진다. ✅

## 14. 중요 포인트 📌

- `INSERT`는 테이블에 데이터를 삽입하는 명령이다.
- `INSERT INTO 테이블명 (열목록) VALUES (값목록)` 형식으로 작성한다.
- 열 이름을 생략하면 값의 순서와 개수가 테이블 정의와 같아야 한다.
- `AUTO_INCREMENT`는 숫자 값을 자동 증가시켜 입력한다.
- `AUTO_INCREMENT`는 `PRIMARY KEY` 또는 `UNIQUE` 컬럼에 사용할 수 있다.
- `AUTO_INCREMENT` 컬럼은 `INSERT`에서 생략하거나 `NULL`을 넣으면 자동 입력된다.
- `INSERT INTO ... SELECT`는 조회 결과를 한 번에 삽입할 때 사용한다.
- `UPDATE`는 기존 데이터를 수정하는 명령이다.
- `UPDATE`에서 `WHERE`절을 생략하면 전체 행이 수정된다.
- 안전 모드에서는 키 컬럼이 아닌 조건으로 수정 시 에러가 발생할 수 있다.
- `DELETE FROM`은 행 단위 데이터를 삭제하는 명령이다.
- `DELETE`에서 `WHERE`절을 생략하면 전체 데이터가 삭제된다.
- `DELETE`는 트랜잭션 로그 기록 때문에 대량 삭제 시 느릴 수 있다.
- `DROP`은 테이블 자체를 삭제한다.
- `TRUNCATE`는 테이블 구조를 남기고 전체 데이터만 빠르게 삭제한다.

## 정리 ✅

SQL 기본2에서는 데이터 삽입, 수정, 삭제 명령이 핵심이다.  
`INSERT`는 새로운 행을 추가할 때 사용하며, 열 이름을 생략하면 값의 순서와 개수가 테이블 정의와 정확히 일치해야 한다.  
`AUTO_INCREMENT`는 숫자 값을 자동으로 증가시켜 입력하는 기능으로, 주로 기본키나 고유키 컬럼에 사용한다.  
`UPDATE`는 기존 데이터를 수정하고, `DELETE FROM`은 행 단위로 데이터를 삭제한다.  
특히 `UPDATE`와 `DELETE`에서 `WHERE`절을 생략하면 전체 행에 영향을 주므로 반드시 주의해야 한다.  
삭제 목적에 따라 일부 행 삭제는 `DELETE`, 테이블 자체 삭제는 `DROP`, 테이블 구조를 유지한 전체 데이터 삭제는 `TRUNCATE`를 사용한다.
