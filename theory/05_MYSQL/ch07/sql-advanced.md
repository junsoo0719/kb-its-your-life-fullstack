# ✨ SQL 고급 - 데이터타입, 내장함수

## 1. 데이터 타입의 개념

데이터 타입은 테이블의 컬럼에 어떤 종류의 데이터를 저장할지 정하는 기준이다.  
MySQL에서는 숫자, 문자, 날짜와 시간, 공간 데이터, JSON 등 다양한 데이터 타입을 제공한다.

데이터 타입을 적절히 선택하면 저장 공간을 효율적으로 사용할 수 있고, 데이터의 의미도 더 명확하게 표현할 수 있다. 📌

## 2. 숫자 데이터 형식

숫자 데이터 형식은 정수나 실수 값을 저장할 때 사용한다.

대표적인 숫자 데이터 형식은 다음과 같다.

- `SMALLINT`
- `INT`
- `BIGINT`
- `FLOAT`
- `DECIMAL(m, [d])`

필기에는 `SMALLINIT`로 적혀 있지만, 정확한 데이터 타입명은 `SMALLINT`이다. ⚠️

## 3. 정수 데이터 타입

정수 데이터 타입은 소수점이 없는 숫자를 저장할 때 사용한다.

대표적인 타입은 다음과 같다.

- `SMALLINT` → 작은 범위의 정수
- `INT` → 일반적인 정수
- `BIGINT` → 큰 범위의 정수

즉, 저장할 숫자의 범위가 작으면 `SMALLINT`, 일반적인 정수는 `INT`, 매우 큰 정수는 `BIGINT`를 사용할 수 있다.

데이터 크기를 고려해서 적절한 타입을 선택하는 것이 중요하다.

## 4. 실수 데이터 타입

실수 데이터 타입은 소수점이 있는 숫자를 저장할 때 사용한다.

대표적인 타입은 다음과 같다.

- `FLOAT`
- `DECIMAL(m, [d])`

`FLOAT`는 근사값 기반의 실수 타입이다.  
따라서 정확한 소수 계산이 필요한 경우에는 주의가 필요하다.

## 5. DECIMAL(m, d)

`DECIMAL(m, [d])`은 전체 자릿수와 소수점 이하 자릿수를 지정해서 숫자를 저장하는 타입이다.

의미는 다음과 같다.

- `m` → 전체 자릿수
- `d` → 소수점 이하 자릿수

예를 들어 다음과 같이 사용할 수 있다.

    DECIMAL(10, 2)

이 경우 전체 10자리 숫자 중 소수점 아래 2자리를 저장할 수 있다.

즉, 금액처럼 정확한 소수 표현이 필요한 데이터에 적합하다. ✅

## 6. 문자 데이터 형식

문자 데이터 형식은 문자열 데이터를 저장할 때 사용한다.

대표적인 문자 데이터 형식은 다음과 같다.

- `CHAR(n)`
- `VARCHAR(n)`
- `LONGTEXT`
- `LONGBLOB`

문자열의 길이가 고정인지, 가변인지, 대용량인지에 따라 적절한 타입을 선택해야 한다.

## 7. CHAR(n)

`CHAR(n)`은 고정 길이 문자열을 저장할 때 사용한다.

특징은 다음과 같다.

- 고정 길이
- `n`은 1부터 255까지 지정 가능
- 지정한 길이만큼 공간을 사용

즉, 항상 길이가 일정한 데이터에 적합하다.

예를 들어 성별 코드, 국가 코드처럼 길이가 정해진 값에 사용할 수 있다. 📌

## 8. VARCHAR(n)

`VARCHAR(n)`은 가변 길이 문자열을 저장할 때 사용한다.

특징은 다음과 같다.

- 가변 길이
- `n`은 최대 길이를 의미
- 실제 저장된 문자열 길이에 따라 공간 사용

즉, 이름, 이메일, 주소처럼 길이가 달라질 수 있는 문자열에 적합하다.

`CHAR`보다 유연하지만, 고정 길이 데이터라면 `CHAR`가 더 적절할 수 있다.

## 9. LONGTEXT와 LONGBLOB

`LONGTEXT`와 `LONGBLOB`은 대용량 데이터를 저장할 때 사용한다.

LOB는 Large Object의 약자로, 대량의 데이터를 의미한다.

- `LONGTEXT` → 대용량 텍스트 저장
- `LONGBLOB` → 대용량 바이너리 데이터 저장

약 4GB 크기의 파일 하나를 하나의 데이터로 저장할 수 있다.

즉, 긴 문서, 이미지, 동영상, 파일 데이터처럼 큰 데이터를 저장할 때 사용할 수 있다. ⚠️

## 10. 날짜와 시간 데이터 형식

날짜와 시간 데이터를 저장할 때는 날짜/시간 전용 타입을 사용한다.

대표적인 타입은 다음과 같다.

- `DATE`
- `DATETIME`

## 11. DATE

`DATE`는 날짜만 저장하는 데이터 타입이다.

형식은 다음과 같다.

    YYYY-MM-DD

예를 들어 다음과 같은 값을 저장할 수 있다.

    2026-05-26

즉, 시간 정보가 필요 없고 날짜만 필요한 경우에 사용한다.

## 12. DATETIME

`DATETIME`은 날짜와 시간을 함께 저장하는 데이터 타입이다.

형식은 다음과 같다.

    YYYY-MM-DD HH:MM:SS

예를 들어 다음과 같은 값을 저장할 수 있다.

    2026-05-26 14:30:00

즉, 특정 시점의 날짜와 시간까지 저장해야 할 때 사용한다. 📌

## 13. 기타 데이터 형식

MySQL에는 숫자, 문자, 날짜 외에도 다양한 특수 데이터 형식이 있다.

대표적인 기타 데이터 형식은 다음과 같다.

- `GEOMETRY`
- `JSON`

## 14. GEOMETRY

`GEOMETRY`는 공간 데이터를 저장하기 위한 데이터 타입이다.

예를 들어 위치, 좌표, 도형 같은 공간 정보를 저장할 때 사용할 수 있다.

즉, 지도나 위치 기반 서비스에서 공간 데이터를 다룰 때 활용할 수 있다.

## 15. JSON

`JSON`은 JSON 형식의 데이터를 저장하기 위한 데이터 타입이다.

JSON은 key-value 형태의 구조화된 데이터를 표현할 때 많이 사용된다.

즉, 고정된 컬럼 구조로 표현하기 어려운 데이터를 유연하게 저장할 때 사용할 수 있다. ✅

## 16. 데이터 타입 선택 기준

데이터 타입을 선택할 때는 다음을 고려해야 한다.

- 저장할 데이터의 종류
- 데이터의 최대 크기
- 고정 길이인지 가변 길이인지
- 정확한 계산이 필요한지
- 날짜만 필요한지, 시간까지 필요한지
- 대용량 데이터인지

즉, 데이터 타입은 단순히 아무거나 선택하는 것이 아니라 저장할 데이터의 성격에 맞게 골라야 한다. 📌

## 17. 중요 포인트 📌

- 숫자 데이터 형식에는 `SMALLINT`, `INT`, `BIGINT`, `FLOAT`, `DECIMAL` 등이 있다.
- 정확한 타입명은 `SMALLINT`이다.
- `DECIMAL(m, d)`에서 `m`은 전체 자릿수, `d`는 소수점 이하 자릿수이다.
- 문자 데이터 형식에는 `CHAR`, `VARCHAR`, `LONGTEXT`, `LONGBLOB` 등이 있다.
- `CHAR(n)`은 고정 길이 문자열이다.
- `VARCHAR(n)`은 가변 길이 문자열이며, `n`은 최대 길이이다.
- `LONGTEXT`와 `LONGBLOB`은 LOB, 즉 대용량 데이터를 저장할 때 사용한다.
- `DATE`는 `YYYY-MM-DD` 형식의 날짜를 저장한다.
- `DATETIME`은 `YYYY-MM-DD HH:MM:SS` 형식의 날짜와 시간을 저장한다.
- `GEOMETRY`는 공간 데이터 형식이다.
- `JSON`은 JSON 구조 데이터를 저장하는 타입이다.
- 데이터 타입은 저장할 데이터의 성격과 크기에 맞게 선택해야 한다.

## 정리 ✅

SQL 고급에서는 컬럼에 저장할 데이터의 성격에 맞게 적절한 데이터 타입을 선택하는 것이 중요하다.  
숫자 데이터는 `SMALLINT`, `INT`, `BIGINT`, `FLOAT`, `DECIMAL` 등을 사용하고, 정확한 소수 표현이 필요하면 `DECIMAL(m, d)`를 사용할 수 있다.  
문자 데이터는 고정 길이인 `CHAR`, 가변 길이인 `VARCHAR`, 대용량 데이터인 `LONGTEXT`, `LONGBLOB`으로 구분할 수 있다.  
날짜와 시간은 `DATE`, `DATETIME`으로 저장하며, 공간 데이터는 `GEOMETRY`, 구조화된 데이터는 `JSON` 타입으로 저장할 수 있다.  
시험 대비에서는 각 데이터 타입의 용도, `CHAR`와 `VARCHAR` 차이, `DECIMAL(m, d)`의 의미, `DATE`와 `DATETIME`의 형식을 함께 정리해 두는 것이 좋다.
