# ✨ SQL 고급2 - 데이터타입, 내장함수

## 1. 데이터 형식과 형 변환
MySQL에서는 데이터의 형식을 다른 형식으로 변환할 수 있다.  
형 변환은 크게 명시적 형 변환과 암시적 형 변환으로 나눌 수 있다.

- 명시적 형 변환 → 사용자가 함수로 직접 변환
- 암시적 형 변환 → MySQL이 상황에 맞게 자동 변환

즉, 데이터 타입이 서로 다른 값끼리 연산하거나 비교할 때 형 변환이 발생할 수 있다. 📌

## 2. 데이터 형식 변환 함수
명시적으로 데이터 형식을 변환할 때는 `CAST()`와 `CONVERT()`를 사용한다.

기본 형식은 다음과 같다.

    CAST(expression AS 데이터형식 [(길이)])

    CONVERT(expression, 데이터형식 [(길이)])

두 함수 모두 특정 표현식을 원하는 데이터 형식으로 변환할 때 사용한다.

예를 들면 문자열을 숫자로 바꾸거나, 숫자를 문자로 바꾸는 상황에서 사용할 수 있다.

## 3. 암시적 형 변환
암시적 형 변환은 MySQL이 연산 상황에 따라 자동으로 데이터 타입을 바꾸는 것이다.

예를 들어 다음 SQL을 보자.

    SELECT '100' + '200';

문자열처럼 보이지만 `+` 연산자가 사용되었기 때문에 MySQL은 문자열을 숫자로 변환해서 계산한다.  
따라서 결과는 문자열 연결이 아니라 숫자 덧셈으로 처리된다.

반대로 문자열을 연결하고 싶다면 `CONCAT()`을 사용해야 한다.

    SELECT CONCAT('100', '200');

이 경우 결과는 문자열로 연결된다.

## 4. 숫자와 문자열 연결
`CONCAT()`은 문자열 연결 함수이다.  
숫자와 문자열을 함께 넣어도 숫자가 문자열로 변환되어 처리된다.

    SELECT CONCAT(100, '200');

이 경우 정수 `100`이 문자열로 변환된 후 `'200'`과 연결된다.

즉,

- `+` → 숫자 연산 중심
- `CONCAT()` → 문자열 연결 중심

으로 구분해야 한다. ⚠️

## 5. 비교 연산에서 암시적 형 변환
문자열과 숫자를 비교할 때도 암시적 형 변환이 발생할 수 있다.

예시는 다음과 같다.

    SELECT 1 > '2mega';
    SELECT 3 > '2MEGA';
    SELECT 0 = 'mega2';

MySQL은 문자열 앞부분에 숫자가 있으면 해당 숫자로 변환해서 비교할 수 있다.

- `'2mega'` → 2로 변환
- `'2MEGA'` → 2로 변환
- `'mega2'` → 숫자로 시작하지 않으므로 0으로 변환

즉, 문자열이 숫자와 비교될 때 의도하지 않은 결과가 나올 수 있으므로 주의해야 한다. 📌

## 6. 내장 함수의 종류
MySQL은 다양한 내장 함수를 제공한다.

대표적인 분류는 다음과 같다.

- 흐름 제어 함수
- 문자열 함수
- 수학 함수
- 날짜/시간 함수
- 전체 텍스트 검색 함수
- 형 변환 함수
- XML 함수
- 비트 함수
- 보안/압축 함수
- 정보 함수
- 공간 분석 함수
- 기타 함수

즉, MySQL 내장 함수는 데이터 조회, 변환, 계산, 조건 처리 등 다양한 작업을 SQL 안에서 처리할 수 있게 해 준다. ✅

## 7. 제어 흐름 함수
제어 흐름 함수는 조건에 따라 다른 값을 반환할 때 사용한다.

대표적인 함수와 표현은 다음과 같다.

- `IF()`
- `IFNULL()`
- `NULLIF()`
- `CASE ~ WHEN ~ ELSE ~ END`

조건에 따라 결과를 다르게 보여주고 싶을 때 사용한다.

## 8. IF()
`IF()`는 조건식이 참인지 거짓인지에 따라 다른 값을 반환한다.

기본 형식은 다음과 같다.

    IF(수식, 참일때값, 거짓일때값)

예를 들면 다음처럼 사용할 수 있다.

    SELECT IF(100 > 50, '참', '거짓');

즉, 조건식이 참이면 두 번째 값, 거짓이면 세 번째 값을 반환한다.

## 9. IFNULL()
`IFNULL()`은 첫 번째 수식이 `NULL`인지 확인한다.

기본 형식은 다음과 같다.

    IFNULL(수식1, 수식2)

의미는 다음과 같다.

- 수식1이 `NULL`이 아니면 → 수식1 반환
- 수식1이 `NULL`이면 → 수식2 반환

즉, `NULL` 대신 기본값을 출력하고 싶을 때 자주 사용한다. 📌

## 10. NULLIF()
`NULLIF()`는 두 수식을 비교해서 같으면 `NULL`, 다르면 첫 번째 수식을 반환한다.

기본 형식은 다음과 같다.

    NULLIF(수식1, 수식2)

의미는 다음과 같다.

- 수식1과 수식2가 같으면 → `NULL`
- 다르면 → 수식1 반환

즉, 특정 값과 같을 때 결과를 `NULL`로 처리하고 싶을 때 사용할 수 있다.

## 11. CASE
`CASE`는 여러 조건을 비교해서 결과를 반환할 때 사용한다.

기본 형식은 다음과 같다.

    CASE
        WHEN 조건1 THEN 결과1
        WHEN 조건2 THEN 결과2
        ELSE 결과3
    END

해당하는 조건이 있으면 그 결과를 반환하고, 해당 사항이 없다면 `ELSE` 부분을 반환한다.

필기 기준으로 `CASE`는 내장 함수가 아니라 연산자로 분류된다.  
하지만 흐름 제어를 할 때 매우 자주 사용된다. ✅

## 12. 문자열 함수
문자열 함수는 문자열을 변환, 검색, 결합, 포맷팅할 때 사용한다.

대표적인 문자열 함수는 다음과 같다.

- `ASCII()`
- `CHAR()`
- `CONCAT()`
- `CONCAT_WS()`
- `GROUP_CONCAT()`
- `ELT()`
- `FIELD()`
- `FIND_IN_SET()`
- `INSTR()`
- `LOCATE()`
- `FORMAT()`
- `BIN()`, `HEX()`, `OCT()`
- `INSERT()`
- `LEFT()`, `RIGHT()`
- `UPPER()`, `LOWER()`
- `LPAD()`, `RPAD()`

문자열 함수는 조회 결과를 가공해서 보여줄 때 자주 사용한다. 📌

## 13. ASCII()와 CHAR()
`ASCII()`는 문자의 아스키 코드값을 반환한다.

    ASCII('A')

`CHAR()`는 숫자의 아스키 코드값에 해당하는 문자를 반환한다.

    CHAR(65)

즉,

- `ASCII()` → 문자에서 숫자 코드로 변환
- `CHAR()` → 숫자 코드에서 문자로 변환

하는 함수이다.

## 14. CONCAT()과 CONCAT_WS()
`CONCAT()`은 여러 문자열을 이어 붙인다.

    CONCAT(문자열1, 문자열2, ...)

예를 들면 다음과 같다.

    SELECT CONCAT('SQL', ' ', 'MySQL');

`CONCAT_WS()`는 구분자와 함께 문자열을 이어 붙인다.

    CONCAT_WS(구분자, 문자열1, 문자열2, ...)

예를 들면 다음과 같다.

    SELECT CONCAT_WS('-', '2026', '05', '27');

즉, 문자열 사이에 구분자를 넣고 싶다면 `CONCAT_WS()`를 사용한다.

## 15. GROUP_CONCAT()
`GROUP_CONCAT()`은 `GROUP BY` 항목의 개별 내용을 하나의 문자열로 연결할 때 사용한다.

구분자를 지정할 수도 있다.

    GROUP_CONCAT(문자열 SEPARATOR '.')

즉, 그룹 안의 여러 값을 하나의 문자열로 합쳐서 보여줄 수 있다.

예를 들어 한 그룹에 속한 이름들을 하나의 문자열로 연결할 때 유용하다. ✅

## 16. ELT()와 FIELD()
`ELT()`는 지정한 위치에 해당하는 문자열을 반환한다.

    ELT(위치, 문자열1, 문자열2, ...)

예를 들어 위치가 2이면 두 번째 문자열을 반환한다.

`FIELD()`는 찾을 문자열이 몇 번째 위치에 있는지 반환한다.

    FIELD(찾을문자열, 문자열1, 문자열2, ...)

찾는 문자열이 없으면 0을 반환한다.

즉,

- `ELT()` → 위치로 문자열 찾기
- `FIELD()` → 문자열로 위치 찾기

로 이해하면 된다.

## 17. FIND_IN_SET()
`FIND_IN_SET()`은 찾을 문자열을 문자열 리스트에서 찾아 위치를 반환한다.

문자열 리스트는 콤마(`,`)로 구분되어 있어야 하며 공백이 없어야 한다.

    FIND_IN_SET('b', 'a,b,c')

이 경우 `b`의 위치를 반환한다.

즉, 콤마로 연결된 목록 안에서 특정 값의 위치를 찾을 때 사용한다. 📌

## 18. INSTR()와 LOCATE()
`INSTR()`는 기준 문자열에서 부분 문자열을 찾아 시작 위치를 반환한다.

    INSTR(기준문자열, 부분문자열)

`LOCATE()`도 같은 기능을 하지만 파라미터 순서가 반대이다.

    LOCATE(부분문자열, 기준문자열)

즉,

- `INSTR(기준, 부분)`
- `LOCATE(부분, 기준)`

으로 구분하면 된다.

## 19. FORMAT()
`FORMAT()`은 숫자를 지정한 소수점 자리수까지 표현하고, 1000단위마다 콤마를 표시한다.

    FORMAT(숫자, 소수점자리수)

예를 들면 다음과 같다.

    SELECT FORMAT(1234567.891, 2);

이 경우 소수점 아래 2자리까지 표시하고, 천 단위 구분 콤마가 포함된다.

즉, 숫자를 보기 좋은 문자열 형식으로 출력할 때 사용한다.

## 20. BIN(), HEX(), OCT()
`BIN()`, `HEX()`, `OCT()`는 숫자를 각각 다른 진법 문자열로 변환한다.

- `BIN(숫자)` → 2진수
- `HEX(숫자)` → 16진수
- `OCT(숫자)` → 8진수

즉, 숫자를 진법 표현으로 바꾸고 싶을 때 사용한다.

## 21. INSERT()
`INSERT()`는 기준 문자열의 특정 위치부터 일정 길이만큼 지우고, 그 자리에 다른 문자열을 삽입한다.

기본 형식은 다음과 같다.

    INSERT(기준문자열, 위치, 길이, 삽입할문자열)

주의할 점은 위치가 인덱스처럼 0부터 시작하는 것이 아니라 1부터 시작한다는 것이다. ⚠️

예를 들어 위치 2부터 3글자를 지우고 다른 문자열을 넣을 수 있다.

## 22. LEFT()와 RIGHT()
`LEFT()`와 `RIGHT()`는 문자열의 왼쪽 또는 오른쪽에서 지정한 길이만큼 반환한다.

    LEFT(문자열, 길이)
    RIGHT(문자열, 길이)

즉,

- `LEFT()` → 왼쪽부터 잘라냄
- `RIGHT()` → 오른쪽부터 잘라냄

으로 이해하면 된다.

## 23. UPPER()와 LOWER()
`UPPER()`는 문자열을 대문자로 변환한다.

    UPPER(문자열)

`LOWER()`는 문자열을 소문자로 변환한다.

    LOWER(문자열)

즉,

- `UPPER()` → 소문자에서 대문자로 변경
- `LOWER()` → 대문자에서 소문자로 변경

하는 함수이다.

## 24. LPAD()와 RPAD()
`LPAD()`와 `RPAD()`는 문자열을 지정한 길이만큼 늘린 뒤 빈 공간을 특정 문자열로 채운다.

기본 형식은 다음과 같다.

    LPAD(문자열, 길이, 채울문자열)
    RPAD(문자열, 길이, 채울문자열)

의미는 다음과 같다.

- `LPAD()` → 왼쪽을 채움
- `RPAD()` → 오른쪽을 채움

예를 들어 코드값의 길이를 맞추거나 출력 형식을 일정하게 만들 때 사용할 수 있다. ✅

## 25. 중요 포인트 📌
- 데이터 형식 변환 함수에는 `CAST()`와 `CONVERT()`가 있다.
- `CAST(expression AS 데이터형식)` 형식으로 사용한다.
- `CONVERT(expression, 데이터형식)` 형식으로 사용한다.
- 암시적 형 변환은 MySQL이 자동으로 타입을 바꾸는 것이다.
- `'100' + '200'`은 문자열 연결이 아니라 정수 연산으로 처리된다.
- 문자열 연결은 `CONCAT()`을 사용한다.
- 숫자와 문자열을 `CONCAT()`하면 숫자가 문자로 변환된다.
- 숫자와 문자열 비교 시 문자열이 숫자로 변환될 수 있다.
- `IF()`는 조건에 따라 참/거짓 값을 반환한다.
- `IFNULL()`은 NULL일 때 대체값을 반환한다.
- `NULLIF()`는 두 값이 같으면 NULL을 반환한다.
- `CASE`는 여러 조건을 처리하는 흐름 제어 표현이다.
- `CONCAT_WS()`는 구분자와 함께 문자열을 연결한다.
- `GROUP_CONCAT()`은 그룹 내 값을 하나의 문자열로 연결한다.
- `ELT()`는 위치로 문자열을 찾고, `FIELD()`는 문자열의 위치를 찾는다.
- `INSTR()`와 `LOCATE()`는 부분 문자열 위치를 찾지만 파라미터 순서가 다르다.
- `FORMAT()`은 숫자를 소수점 자리수와 콤마 형식으로 표현한다.
- `INSERT()`의 위치는 1부터 시작한다.
- `UPPER()`는 대문자 변환, `LOWER()`는 소문자 변환 함수이다.
- `LPAD()`와 `RPAD()`는 문자열 길이를 맞추고 빈 공간을 채운다.

## 정리 ✅
SQL 고급2에서는 데이터 형식 변환과 MySQL 내장 함수가 핵심이다.  
`CAST()`와 `CONVERT()`는 명시적 형 변환에 사용되며, MySQL은 연산이나 비교 상황에 따라 암시적 형 변환을 수행하기도 한다.  
특히 `'100' + '200'`은 문자열 연결이 아니라 숫자 연산으로 처리되므로 문자열 연결에는 `CONCAT()`을 사용해야 한다.  
제어 흐름 함수로는 `IF()`, `IFNULL()`, `NULLIF()`, `CASE`가 있으며, 문자열 함수로는 `CONCAT()`, `CONCAT_WS()`, `GROUP_CONCAT()`, `INSTR()`, `LOCATE()`, `FORMAT()`, `INSERT()`, `LEFT()`, `RIGHT()`, `UPPER()`, `LOWER()`, `LPAD()`, `RPAD()` 등이 있다.  
시험 대비에서는 명시적/암시적 형 변환 차이, 문자열 연결 방식, 제어 흐름 함수의 의미, 주요 문자열 함수의 역할을 함께 정리해 두는 것이 중요하다.
