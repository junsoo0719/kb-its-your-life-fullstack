# ✨ MySQL 전체 운영 실습

## 1. 쿼리의 개념

쿼리는 데이터베이스에 명령을 전달하기 위해 작성하는 문장이다.  
MySQL에서는 쿼리를 이용해 데이터베이스 선택, 테이블 조회, 데이터 추가, 수정, 삭제 등의 작업을 수행한다.

즉, 쿼리는 MySQL과 대화하기 위한 명령문이라고 볼 수 있다. 📌

## 2. 주석 작성

MySQL에서 한 줄 주석을 작성할 때는 `--`를 사용한다.

    -- 주석 내용

주석은 실제로 실행되지 않고, 코드 설명을 위해 사용한다.  
쿼리가 길어지거나 특정 명령의 의미를 남기고 싶을 때 사용하면 좋다.

## 3. 쿼리 실행 단축키

쿼리를 실행할 때는 다음 단축키를 사용할 수 있다.

    Ctrl + Enter

즉, 작성한 SQL 문장을 빠르게 실행할 때 사용하는 단축키이다. ✅

## 4. 디폴트 데이터베이스 설정

특정 데이터베이스를 기본으로 사용하려면 `USE` 문을 사용한다.

    USE employees;

이렇게 설정하면 이후 실행하는 쿼리는 기본적으로 `employees` 데이터베이스를 대상으로 실행된다.

즉, 매번 데이터베이스명을 직접 붙이지 않아도 되도록 기본 작업 공간을 지정하는 것이다.

## 5. SQL 작성 관례

SQL을 작성할 때는 일반적으로 다음 관례를 따른다.

- 키워드 → 대문자
- 사용자 지정 이름 → 소문자

예를 들어 다음과 같이 작성할 수 있다.

    SELECT *
    FROM employees;

여기서 `SELECT`, `FROM`은 SQL 키워드이므로 대문자로 작성하고, `employees`는 사용자가 지정한 테이블 이름이므로 소문자로 작성한다.

이 관례를 따르면 SQL 문장을 더 읽기 쉽게 만들 수 있다. 📌

## 6. 중요 포인트 📌

- 쿼리는 데이터베이스에 명령을 전달하는 SQL 문장이다.
- MySQL 주석은 `--`로 작성한다.
- 쿼리 실행 단축키는 `Ctrl + Enter`이다.
- 기본 데이터베이스는 `USE 데이터베이스명;`으로 설정한다.
- `USE employees;`는 `employees` 데이터베이스를 기본 작업 대상으로 지정한다.
- SQL 키워드는 대문자로 작성하는 것이 일반적이다.
- 데이터베이스명, 테이블명, 컬럼명 같은 사용자 지정 이름은 소문자로 작성하는 것이 일반적이다.

## 정리 ✅

MySQL 전체 운영 실습에서는 쿼리 작성의 기본 규칙을 먼저 익히는 것이 중요하다.  
쿼리는 데이터베이스에 명령을 전달하는 문장이며, 주석은 `--`로 작성하고 실행은 `Ctrl + Enter` 단축키를 사용할 수 있다.  
기본 데이터베이스를 설정할 때는 `USE employees;`처럼 작성하며, 이후 쿼리는 해당 데이터베이스를 기준으로 실행된다.  
또한 SQL 작성 시 키워드는 대문자, 사용자 지정 이름은 소문자로 작성하는 관례를 따르면 쿼리의 가독성이 좋아진다.
