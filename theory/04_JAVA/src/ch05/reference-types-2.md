# ✨ 참조 타입2

## 1. 열거(Enum) 타입

열거 타입(Enum)은 서로 관련된 상수들을 하나의 타입으로 묶어서 관리하는 방법이다.  
즉, 정해진 값들만 사용할 수 있게 제한하는 상수 집합 타입이라고 볼 수 있다. 📌

예를 들어 요일, 계절, 상태값처럼 미리 정해진 값만 사용해야 하는 경우에 적합하다.

## 2. 열거 타입의 특징

열거 타입은 상수화된 값을 표현하기 위해 사용한다.  
문법적으로는 특별한 형태이지만, 번역되어 실행될 때는 클래스처럼 동작한다.

즉, enum은 단순한 숫자 모음이 아니라 자바에서 하나의 특별한 클래스 형태로 운영된다고 이해하면 된다.

## 3. enum 선언

열거 타입은 `enum` 키워드를 사용해서 선언한다.

예를 들어 다음과 같이 작성할 수 있다.

    public enum Week {
        MONDAY, TUESDAY, WEDNESDAY
    }

상수 이름은 자바 상수의 명명 관례를 따른다.

- 대문자 사용
- 단어가 여러 개면 언더바(`_`) 사용

즉, enum 안에 선언되는 값들은 일반 변수명이 아니라 상수처럼 작성해야 한다. ✅

## 4. 별도 파일로 관리

자바에서는 클래스를 보통 별도의 파일로 만들어 관리하는 것을 권장한다.  
열거 타입도 마찬가지로 별도의 파일로 만들어 관리하는 것이 좋다.

즉,

- 클래스 → 별도 파일 권장
- enum → 별도 파일 권장

으로 이해하면 된다.

필기 내용처럼 파일 생성 시 카테고리를 Enum으로 만들어 따로 관리하는 방식이 자바 권장 스타일에 가깝다.

## 5. 참조 타입으로서의 enum

열거 타입은 참조 타입이다.  
즉, 기본 타입처럼 값 자체를 저장하는 것이 아니라 객체처럼 참조하는 방식으로 동작한다.

그래서 다음과 같은 특징이 있다.

- `null`로 초기화 가능
- 참조 변수처럼 다룰 수 있음

즉, enum도 클래스, 배열, 문자열처럼 참조 타입의 성질을 가진다.

## 6. enum은 직접 new 불가

열거 타입은 미리 정의된 값만 사용해야 하므로 직접 `new` 연산자로 객체를 생성할 수 없다. ⚠️

즉, enum의 상수들은 프로그램에서 정해진 개수만 존재하고, 사용자가 임의로 새로운 값을 추가 생성할 수 없다.

이 점 때문에 enum은 "정해진 값만 사용해야 하는 상황"에 매우 적합하다.

## 7. Calendar 객체 얻기

날짜와 시간 관련 정보를 다룰 때는 `Calendar` 객체를 사용할 수 있다.

객체를 얻는 방법은 다음과 같다.

    Calendar cal = Calendar.getInstance();

즉, `new Calendar()`처럼 직접 생성하는 것이 아니라 `getInstance()` 메소드를 통해 객체를 가져온다.

이 방식은 Calendar가 대표적으로 팩토리 메소드 방식처럼 사용되는 예라고 볼 수 있다.

## 8. Calendar 정보 얻기

Calendar 객체에서 필요한 정보는 `get()` 메소드를 사용해 가져온다.

형식은 다음과 같다.

    cal.get(정보의 종류)

예를 들어 요일 정보를 얻고 싶다면 다음과 같이 사용한다.

    cal.get(Calendar.DAY_OF_WEEK)

이 값은 숫자로 반환되며 범위는 다음과 같다.

- 1 ~ 7
- 일요일 ~ 토요일

즉, 요일을 문자열로 바로 주는 것이 아니라 숫자 코드 형태로 반환한다고 이해하면 된다. 📌

## 9. 싱글톤 패턴과 enum

열거 타입의 각 상수는 오직 하나만 만들어져서 운영된다.  
즉, 같은 enum 상수는 프로그램 안에서 하나의 인스턴스만 존재한다.

이 점은 싱글톤 패턴과 연결해서 이해할 수 있다.

- 각 상수는 하나만 존재
- 같은 상수는 같은 객체를 참조
- 중복 생성되지 않음

즉, enum 상수는 본질적으로 싱글톤처럼 운영된다고 볼 수 있다. ✅

## 10. enum과 동등 연산자 비교

enum 상수는 하나의 객체만 존재하기 때문에 동등 연산자 `==`로 비교할 수 있다.

예를 들어 같은 enum 상수인지 확인할 때

    if (today == Week.MONDAY) {
        ...
    }

처럼 비교가 가능하다.

이것은 enum 상수가 오직 하나만 존재하기 때문에 가능한 장점이다.  
즉, 문자열처럼 `equals()`를 쓰지 않아도 `==` 비교가 안전하다는 점이 enum의 큰 특징이다. 📌

## 11. 중요 포인트 📌

- 열거 타입은 관련된 상수들을 하나의 타입으로 묶는 방식이다.
- enum은 실행 시 클래스처럼 동작한다.
- 선언할 때는 `enum` 키워드를 사용한다.
- enum 상수명은 대문자와 언더바 규칙을 따른다.
- enum도 별도의 파일로 관리하는 것이 좋다.
- enum은 참조 타입이므로 `null` 초기화가 가능하다.
- enum은 사전 정의된 값이므로 `new`로 직접 생성할 수 없다.
- `Calendar` 객체는 `Calendar.getInstance()`로 얻는다.
- `cal.get(Calendar.DAY_OF_WEEK)`는 요일 정보를 숫자로 반환한다.
- enum 상수는 각각 하나만 존재하므로 싱글톤처럼 동작한다.
- enum은 `==`로 비교할 수 있다.

## 정리 ✅

열거 타입(Enum)은 서로 관련된 상수들을 하나의 타입으로 묶어서 안전하게 관리하는 방법이다.  
문법상 특별한 구조이지만 실행 시에는 클래스처럼 동작하며, 참조 타입이기 때문에 `null` 초기화도 가능하다.  
다만 enum은 미리 정의된 값만 사용해야 하므로 직접 `new`로 생성할 수 없다.  
또한 Calendar 객체를 이용하면 날짜와 요일 같은 정보를 얻을 수 있으며, enum 상수는 하나만 생성되어 운영되므로 싱글톤처럼 동작하고 `==` 비교도 가능하다는 점이 중요하다.
