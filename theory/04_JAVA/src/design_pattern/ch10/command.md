# ✨ Command - 명령을 클래스로 표현한다

## 1. Command 패턴의 개념

Command 패턴은 명령 자체를 하나의 클래스로 표현하는 디자인 패턴이다.  
즉, 실행할 동작을 그냥 메소드 호출로 끝내는 것이 아니라, 별도의 객체로 만들어 다루는 방식이다. 📌

이 패턴을 사용하면 "무엇을 실행할지"를 객체로 보관하고, 필요할 때 실행할 수 있다.

## 2. Command 클래스의 역할

Command 클래스는 명령의 집합을 저장하는 역할을 한다.

즉, 단순히 즉시 실행하는 것이 아니라 명령을 객체 형태로 보관해 둘 수 있다.  
이렇게 하면 다음과 같은 작업이 가능해진다.

- 나중에 실행
- 여러 명령을 모아서 관리
- 실행할 명령 교체
- 같은 방식으로 여러 명령 처리

즉, 명령을 데이터처럼 다룰 수 있게 된다는 점이 핵심이다. ✅

## 3. 이벤트 구동형 프로그래밍과 Command 패턴

Command 패턴은 이벤트 구동형 프로그래밍에서 자주 사용된다.  
대표적으로 GUI 프로그래밍과 연결된다.

예를 들어 버튼 클릭 같은 이벤트가 발생했을 때, 버튼이 직접 모든 동작을 구현하는 것이 아니라 "실행할 명령 객체"를 가지고 있다가 그 명령을 실행하도록 만들 수 있다.

즉,

- 이벤트 발생
- 연결된 명령 객체 실행

의 흐름으로 동작한다고 이해하면 된다.

이렇게 하면 화면 요소와 실제 동작을 분리할 수 있어서 구조가 더 깔끔해진다. 📌

## 4. Command 인터페이스

Command 패턴에서는 보통 공통 명령 규칙을 인터페이스로 정의한다.

예시는 다음과 같다.

    public interface Command {
        void execute();
    }

이 인터페이스는 명령을 추상화한 것이다.  
즉, 실제로 어떤 일을 하는지는 다르더라도 모두 `execute()`라는 같은 방식으로 실행할 수 있게 만든다.

## 5. execute() 메소드의 의미

`execute()` 메소드는 명령을 실행하는 핵심 메소드이다.

필기 내용 기준으로 보면 이 메소드는 다음 특징을 가진다.

- 매개변수 없음
- 리턴값 없음

즉, "명령을 실행하라"는 동작 자체만 공통 규칙으로 정의한 것이다.

이렇게 하면 사용하는 쪽에서는 내부 구현을 몰라도 그냥 `execute()`만 호출하면 된다.  
즉, 명령의 사용 방법을 통일할 수 있다.

## 6. 명령의 추상화

Command 패턴에서 중요한 점은 명령을 추상화한다는 것이다.

즉, 실제 명령이 무엇인지와 상관없이 공통 인터페이스로 다룰 수 있다.

예를 들면 다음처럼 생각할 수 있다.

- 전등 켜기 명령
- 문 열기 명령
- 파일 저장 명령

이런 명령들은 실제 동작은 다르지만, 모두 `execute()`라는 공통 방식으로 실행할 수 있다.

즉, "명령의 종류"와 "명령의 실행 방식"을 분리해서 다루는 것이다. ✅

## 7. Command 패턴의 장점

Command 패턴을 사용하면 다음과 같은 장점이 있다.

- 실행할 동작을 객체로 분리할 수 있음
- 호출하는 쪽과 실제 동작을 수행하는 쪽을 분리할 수 있음
- 새로운 명령을 추가해도 기존 코드 수정이 적음
- 명령을 저장하거나 모아서 관리할 수 있음

즉, 구조를 더 유연하게 만들고, 확장하기 쉬운 코드를 작성할 수 있게 도와준다.

## 8. 호출자와 수행자의 분리

Command 패턴은 보통 다음 구조로 이해하면 쉽다.

- 호출자(Invoker) → 명령 실행 요청
- 명령(Command) → 공통 실행 규칙
- 실제 수행 객체(Receiver) → 진짜 작업 수행

즉, 버튼이나 메뉴 같은 호출자는 "무슨 명령인지"만 알고 실행시키고, 실제 작업은 다른 객체가 맡게 된다.

이 구조 덕분에 GUI 요소와 실제 비즈니스 로직을 분리할 수 있다. 📌

## 9. 중요 포인트 📌

- Command 패턴은 명령을 클래스로 표현하는 패턴이다.
- 실행할 동작을 객체처럼 다룰 수 있다.
- 명령을 저장하거나 모아서 관리할 수 있다.
- GUI 같은 이벤트 구동형 프로그래밍에서 자주 사용된다.
- `Command` 인터페이스는 명령의 공통 규칙을 정의한다.
- `execute()`는 명령 실행을 위한 핵심 메소드이다.
- `execute()`는 매개변수와 리턴값 없이 동작을 추상화할 수 있다.
- Command 패턴은 호출하는 쪽과 실제 수행하는 쪽을 분리한다.
- 새로운 명령을 추가하기 쉬워 확장성이 좋다.

## 정리 ✅

Command 패턴은 실행할 명령을 하나의 클래스로 표현해서 객체처럼 다루는 디자인 패턴이다.  
이 패턴을 사용하면 명령을 저장하고, 교체하고, 같은 방식으로 실행할 수 있으며, 특히 GUI 같은 이벤트 구동형 프로그래밍에서 자주 활용된다.  
`Command` 인터페이스는 명령 실행 규칙을 정의하고, `execute()` 메소드는 실제 명령 실행의 공통 진입점 역할을 한다.  
핵심은 명령을 추상화해서 호출하는 쪽과 실제 작업을 수행하는 쪽을 분리하는 데 있다.
