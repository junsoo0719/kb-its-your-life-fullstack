# ✨ 조건문과 반복문

## 1. 조건문과 반복문의 의미

조건문은 주어진 조건에 따라 실행 흐름을 나누는 문장이고, 반복문은 같은 작업을 여러 번 반복해서 실행하는 문장이다.

즉, 프로그램의 흐름을 제어하는 가장 기본적인 문법이라고 볼 수 있다. 📌  
조건문은 "어떤 경우에 실행할지"를 결정하고, 반복문은 "몇 번 또는 언제까지 실행할지"를 결정한다.

## 2. 랜덤한 수 만들기

자바에서 랜덤한 수를 만들 때는 `Math.random()`을 사용한다.

    Math.random()

이 메소드는 다음 범위의 `double` 타입 난수를 반환한다.

- `0.0 <= 난수 < 1.0`

즉,

- 0은 포함
- 1은 포함하지 않음

이라는 점을 기억해야 한다. ⚠️

## 3. 정수 범위의 랜덤 수 만들기

주사위처럼 특정 범위의 정수를 만들고 싶다면 `Math.random()` 결과를 가공해야 한다.

예를 들어 1부터 6까지의 정수를 만들려면 다음과 같이 작성한다.

    (int)(Math.random() * 6) + 1

이 식의 의미는 다음과 같다.

- `Math.random()` → 0.0 이상 1.0 미만의 실수 생성
- `* 6` → 0.0 이상 6.0 미만 범위로 확대
- `(int)` → 소수점 버리고 정수로 변환
- `+ 1` → 시작 숫자를 1로 맞춤

즉, 결과적으로 `1 ~ 6` 범위의 정수가 만들어진다.

여기서 특히 중요한 점은 형변환 위치이다.  
`(int)Math.random() * 6 + 1`처럼 쓰면 원하는 값이 나오지 않을 수 있으므로 괄호를 잘 써야 한다. 📌

## 4. switch문의 변수

`switch`문에 사용할 수 있는 변수 타입은 제한되어 있다.

사용 가능한 타입은 다음과 같다.

- 정수 타입
- `String`

실수 타입은 사용할 수 없다. ⚠️

즉, `switch`문은 비교 가능한 정수형 값이나 문자열에 대해서 분기할 수 있다고 이해하면 된다.

## 5. switch문에서 여러 case 처리

`switch`문에서는 같은 실행문을 여러 값에 대해 적용할 수 있다.

예를 들어 다음과 같이 쓰면 된다.

    case 8:
    case 9:
        // 실행문

이 구조는 값이 8 또는 9일 때 같은 코드를 실행하겠다는 뜻이다.  
즉, OR 조건처럼 사용할 수 있다.

## 6. Java 12 이후의 switch문

Java 12 이후에는 `switch`문을 더 간단하게 쓸 수 있다.

예를 들면 다음과 같다.

    case 'A', 'a' -> {
        // 실행문
    }

이 방식의 특징은 다음과 같다.

- 여러 값을 쉼표로 나열해서 OR 표현 가능
- `break`를 따로 쓰지 않아도 됨

즉, 예전보다 코드가 더 짧고 읽기 쉬워졌다. ✅

## 7. for문의 카운트 변수

`for`문의 카운트 변수로는 보통 정수 타입을 사용한다.

특히 `float`를 카운트 변수로 사용하는 것은 피하는 것이 좋다.  
그 이유는 실수는 오차가 발생할 수 있기 때문이다.

즉, 반복 횟수를 정확하게 세어야 하는 `for`문에서는 실수보다 `int` 같은 정수 타입이 더 안전하다. ⚠️

## 8. 중첩 for문

`for`문 안에 또 다른 `for`문이 들어가는 구조를 중첩 `for`문이라고 한다.

이때 보통 다음과 같이 이해한다.

- 바깥쪽 루프 → 높은 차원
- 안쪽 루프 → 낮은 차원

예를 들어 2차원 배열이나 별 찍기처럼 행과 열을 다루는 경우에 자주 사용된다.

즉, 바깥쪽은 큰 흐름을 반복하고, 안쪽은 그 안에서 세부 반복을 수행한다고 보면 된다.

## 9. 중첩 루프와 break

중첩 루프에서 `break`를 사용하면 기본적으로 안쪽 루프만 종료된다.

즉,

- 안쪽 루프에서 `break` → 안쪽 반복문만 종료
- 바깥쪽 루프는 계속 진행

이 점을 헷갈리기 쉽기 때문에 주의해야 한다. 📌

## 10. 라벨을 이용한 반복문 종료

중첩 루프에서 바깥 루프까지 완전히 종료하고 싶다면 라벨을 사용할 수 있다.

즉, 특정 반복문에 이름을 붙이고 `break 라벨명;` 형태로 종료 범위를 지정하는 방식이다.

이 방법을 사용하면 단순한 `break`보다 더 바깥쪽 루프까지 한 번에 빠져나올 수 있다.

즉, 중첩 반복이 깊을 때 원하는 반복문을 정확히 종료할 수 있도록 도와주는 기능이다.

## 11. 중요 포인트 📌

- `Math.random()`은 `0.0 <= 값 < 1.0` 범위의 `double` 값을 반환한다.
- 정수 범위의 랜덤 수는 `(int)(Math.random() * 범위) + 시작값` 형태로 만든다.
- `switch`문에는 실수 타입을 사용할 수 없다.
- `switch`문에서는 여러 `case`를 이어서 OR처럼 처리할 수 있다.
- Java 12 이후에는 `case 값1, 값2 -> {}` 형태를 사용할 수 있고 `break`가 필요 없다.
- `for`문의 카운트 변수로 `float` 사용은 피하는 것이 좋다.
- 중첩 `for`문에서 바깥쪽은 높은 차원, 안쪽은 낮은 차원을 담당한다.
- 중첩 루프에서 `break`는 기본적으로 안쪽 루프만 종료한다.
- 바깥 루프까지 종료하려면 라벨을 사용해야 한다.

## 정리 ✅

조건문과 반복문은 프로그램의 실행 흐름을 제어하는 핵심 문법이다.  
`Math.random()`을 이용하면 랜덤 값을 만들 수 있고, 형변환과 범위 조절을 통해 원하는 정수 범위의 난수를 만들 수 있다.  
또한 `switch`문은 정수와 문자열에 대해 사용할 수 있으며, Java 12 이후에는 더 간단한 문법으로 여러 값을 함께 처리할 수 있다.  
반복문에서는 `for`문의 카운트 변수로 정수 타입을 사용하는 것이 안전하고, 중첩 루프에서는 `break`의 범위를 정확히 이해해야 한다.  
특히 안쪽 루프만 종료되는지, 바깥 루프까지 종료하려면 라벨이 필요한지를 구분하는 것이 중요하다.
