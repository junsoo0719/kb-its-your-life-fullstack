# ✨ MongoDB Java 연동

## 1. MongoDB Java 연동의 개념

MongoDB Java 연동은 Java 애플리케이션에서 MongoDB 데이터베이스에 접근해 데이터를 조회, 삽입, 수정, 삭제할 수 있도록 연결하는 방식이다.

Java에서는 MongoDB Java Driver를 사용해 MongoDB와 통신할 수 있다.  
이때 조회 조건을 작성할 때는 MongoDB에서 제공하는 필터 메서드를 사용할 수 있다. 📌

## 2. 비교 연산자

MongoDB Java Driver에서는 조회 조건을 작성할 때 비교 연산자를 메서드 형태로 사용할 수 있다.

대표적인 비교 연산자는 다음과 같다.

- `eq`
- `ne`
- `lt`
- `lte`
- `gt`
- `gte`
- `in`
- `nin`

이 연산자들은 특정 필드의 값이 조건에 맞는 도큐먼트를 찾을 때 사용한다.

## 3. eq

`eq`는 지정된 값과 같은 값을 찾을 때 사용한다.

즉, 특정 필드가 주어진 값과 정확히 일치하는 도큐먼트를 조회한다.

예를 들면 다음과 같은 의미이다.

    필드 == 값

사용 예시는 다음과 같다.

    eq("username", "smith")

이 조건은 `username` 값이 `"smith"`인 도큐먼트를 찾는다.

## 4. ne

`ne`는 지정된 값과 같지 않은 모든 값을 찾을 때 사용한다.

즉, 특정 필드가 주어진 값이 아닌 도큐먼트를 조회한다.

의미는 다음과 같다.

    필드 != 값

사용 예시는 다음과 같다.

    ne("username", "smith")

이 조건은 `username` 값이 `"smith"`가 아닌 도큐먼트를 찾는다.

## 5. lt

`lt`는 지정된 값보다 작은 값을 찾을 때 사용한다.

의미는 다음과 같다.

    필드 < 값

사용 예시는 다음과 같다.

    lt("age", 20)

이 조건은 `age` 값이 20보다 작은 도큐먼트를 찾는다.

## 6. lte

`lte`는 지정된 값보다 작거나 같은 값을 찾을 때 사용한다.

의미는 다음과 같다.

    필드 <= 값

사용 예시는 다음과 같다.

    lte("age", 20)

이 조건은 `age` 값이 20 이하인 도큐먼트를 찾는다.

## 7. gt

`gt`는 지정된 값보다 큰 값을 찾을 때 사용한다.

의미는 다음과 같다.

    필드 > 값

사용 예시는 다음과 같다.

    gt("age", 20)

이 조건은 `age` 값이 20보다 큰 도큐먼트를 찾는다.

## 8. gte

`gte`는 지정된 값보다 크거나 같은 값을 찾을 때 사용한다.

의미는 다음과 같다.

    필드 >= 값

사용 예시는 다음과 같다.

    gte("age", 20)

이 조건은 `age` 값이 20 이상인 도큐먼트를 찾는다.

## 9. in

`in`은 배열에 지정된 값 중 하나와 일치하는 값을 찾을 때 사용한다.

즉, 여러 후보 값 중 하나라도 일치하면 조회된다.

사용 예시는 다음과 같다.

    in("status", "A", "B", "C")

이 조건은 `status` 값이 `"A"`, `"B"`, `"C"` 중 하나인 도큐먼트를 찾는다. ✅

## 10. nin

`nin`은 배열에 지정된 값과 일치하지 않는 값을 찾을 때 사용한다.

즉, 여러 후보 값에 포함되지 않는 도큐먼트를 조회한다.

사용 예시는 다음과 같다.

    nin("status", "A", "B", "C")

이 조건은 `status` 값이 `"A"`, `"B"`, `"C"`가 아닌 도큐먼트를 찾는다.

## 11. static 메서드 임포트

MongoDB Java Driver의 필터 메서드는 static 메서드 임포트를 사용하면 더 간단하게 작성할 수 있다.

예를 들면 다음과 같이 작성한다.

    import static com.mongodb.client.model.Filters.eq;

이렇게 하면 `Filters.eq()`처럼 클래스명을 붙이지 않고 바로 `eq()`를 사용할 수 있다.

    collection.find(eq("username", "smith"));

즉, static import를 사용하면 조건식을 더 짧고 읽기 쉽게 작성할 수 있다. 📌

## 12. 비교 연산자 정리

MongoDB Java 연동에서 비교 연산자는 조회 조건을 만들 때 사용한다.

정리하면 다음과 같다.

| 연산자 | 의미                           |
| ------ | ------------------------------ |
| `eq`   | 지정된 값과 같음               |
| `ne`   | 지정된 값과 같지 않음          |
| `lt`   | 지정된 값보다 작음             |
| `lte`  | 지정된 값보다 작거나 같음      |
| `gt`   | 지정된 값보다 큼               |
| `gte`  | 지정된 값보다 크거나 같음      |
| `in`   | 지정된 값 목록 중 하나와 일치  |
| `nin`  | 지정된 값 목록과 일치하지 않음 |

이 연산자들은 MongoDB의 쿼리 조건을 Java 코드에서 표현하는 방법이라고 이해하면 된다.

## 13. 중요 포인트 📌

- MongoDB Java 연동에서는 Java 코드에서 MongoDB 데이터를 조회하고 조작할 수 있다.
- 비교 연산자는 조회 조건을 만들 때 사용한다.
- `eq`는 같은 값 조회에 사용한다.
- `ne`는 같지 않은 값 조회에 사용한다.
- `lt`, `lte`, `gt`, `gte`는 범위 조건에 사용한다.
- `in`은 여러 값 중 하나와 일치하는 조건에 사용한다.
- `nin`은 여러 값과 일치하지 않는 조건에 사용한다.
- `static import`를 사용하면 `Filters.eq()` 대신 `eq()`처럼 간단하게 작성할 수 있다.
- `import static com.mongodb.client.model.Filters.eq;` 형태로 임포트한다.

## 정리 ✅

MongoDB Java 연동에서는 Java 애플리케이션에서 MongoDB에 접근해 데이터를 다룰 수 있으며, 조회 조건은 MongoDB Java Driver의 필터 메서드로 작성할 수 있다.  
비교 연산자에는 `eq`, `ne`, `lt`, `lte`, `gt`, `gte`, `in`, `nin`이 있으며, 각각 같음, 같지 않음, 범위 비교, 목록 포함 여부를 표현한다.  
또한 `static import`를 사용하면 `Filters.eq()`처럼 클래스명을 붙이지 않고 `eq()`만으로 간단하게 조건을 작성할 수 있다.  
시험 대비에서는 각 비교 연산자의 의미와 static 메서드 임포트를 통해 코드가 어떻게 간소화되는지 함께 정리해 두는 것이 중요하다.
