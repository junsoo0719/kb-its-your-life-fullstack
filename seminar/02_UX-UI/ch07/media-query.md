# Media Query

## 1. 개념

Media Query는 화면 크기나 디바이스 조건에 따라 다른 CSS를 적용할 수 있게 해 주는 기능이다.

즉, 같은 HTML 구조를 사용하더라도 화면 너비에 따라 레이아웃, 글자 크기, 배치 방식을 다르게 적용할 수 있다.

이 기능은 반응형 웹을 만들 때 핵심적으로 사용된다.

## 2. 반응형 웹(Responsive Web)

반응형 웹은 다양한 화면 크기에 맞게 레이아웃이 변하는 웹이다.

하나의 코드로 모바일, 태블릿, 데스크탑 등 여러 디바이스에 대응할 수 있다는 점이 특징이다.

반응형 웹이 필요한 이유는 다음과 같다.

- 화면이 작아지면 글자가 깨질 수 있다.
- 화면이 작아지면 레이아웃이 무너질 수 있다.
- 다양한 기기에서 같은 서비스를 사용해야 한다.

즉, 반응형 웹은 화면 크기가 달라도 사용자가 불편하지 않도록 구조를 자동으로 조정하는 방식이다.

## 3. 반응형 웹을 만드는 방법

반응형 웹은 크게 두 가지 방식으로 만들 수 있다.

### 3.1 CSS 자체의 유연한 레이아웃 활용

CSS의 레이아웃 기능만으로도 어느 정도 반응형 처리가 가능하다.

대표적인 예시는 다음과 같다.

- `flex`
- `grid`
- `minmax`
- `auto-fit`

이 기능들은 요소 크기와 배치를 유연하게 만들어 화면 크기가 달라져도 구조가 자연스럽게 유지되도록 도와준다.

### 3.2 화면 크기에 따라 다른 스타일 적용

화면 크기 조건에 따라 CSS를 따로 적용하는 방법이다.  
이때 사용하는 기능이 바로 **Media Query**이다.

즉,

- 기본 구조를 유연하게 만들고
- 필요한 구간에서 Media Query로 추가 조정하는 방식이 가장 일반적이다.

## 4. Media Query 문법

Media Query의 기본 문법은 다음과 같다.

```css
@media (조건) {
  선택자 {
    스타일;
  }
}
```

예를 들면 다음과 같이 사용할 수 있다.

```css
@media (max-width: 767px) {
  .container {
    flex-direction: column;
  }
}
```

이 코드는 화면 너비가 `767px 이하`일 때만 `.container`에 `flex-direction: column`을 적용한다.

## 5. 자주 사용하는 조건

Media Query에서 자주 사용하는 조건은 `max-width`와 `min-width`이다.

### 5.1 max-width

지정한 값보다 화면이 작아지면, 즉 **해당 값 이하일 때** 스타일을 적용한다.

```css
@media (max-width: 767px) {
  body {
    font-size: 14px;
  }
}
```

### 5.2 min-width

지정한 값보다 화면이 커지면, 즉 **해당 값 이상일 때** 스타일을 적용한다.

```css
@media (min-width: 1024px) {
  body {
    font-size: 18px;
  }
}
```

즉,

- `max-width`는 작은 화면 대응
- `min-width`는 큰 화면 대응
  이라고 이해하면 된다.

## 6. 브레이크포인트(Breakpoint)

브레이크포인트는 레이아웃이 깨지기 시작하는 지점을 기준으로 화면 구간을 나누는 것이다.

즉, 화면이 특정 너비에 도달했을 때 레이아웃을 바꿔야 하는 기준점이다.

보통 다음과 같이 구분한다.

- 모바일: `~767px`
- 태블릿: `768px~1023px`
- 데스크탑: `1024px~`

여기서 중요한 점은 **브레이크포인트는 정답이 있는 숫자가 아니라 레이아웃이 깨지는 지점을 기준으로 정한다는 것**이다.

즉, 무조건 외우는 값이 아니라 화면 구조를 보고 판단해야 한다.

## 7. 모바일부터 만드는 이유

반응형 웹은 보통 **모바일부터 먼저 설계**하는 방식이 많이 사용된다.

그 이유는 다음과 같다.

- 모바일 사용 비율이 높다.
- 화면이 가장 좁아서 제약이 크다.
- 작은 화면에서 먼저 구조를 단순하게 잡으면, 큰 화면으로 확장하기 쉽다.

이 방식을 보통 **모바일 퍼스트(Mobile First)**라고 한다.

즉, 먼저 작은 화면 기준으로 만들고, 필요하면 `min-width`를 이용해 태블릿과 데스크탑으로 확장한다.

## 8. 반응형이 필요한 경우

다음과 같은 서비스는 반응형이 매우 중요하다.

- 다양한 기기에서 사용하는 서비스
- 모바일 사용 비율이 높은 서비스
- 쇼핑몰
- SNS
- 포털 사이트

이런 서비스는 사용자가 어떤 기기에서 접속할지 예측하기 어렵기 때문에, 화면 크기에 맞게 레이아웃을 조정할 필요가 있다.

## 9. 반응형이 필요하지 않은 경우

모든 웹이 반드시 반응형일 필요는 없다.

예를 들어 다음과 같은 경우는 반응형 필요성이 낮을 수 있다.

- 관리자 시스템
- 특정 환경에서만 사용하는 시스템
- 고정된 해상도에서만 사용하는 프로그램

즉, 사용 환경이 명확하고 디바이스가 제한되어 있다면 굳이 복잡한 반응형 설계를 하지 않아도 된다.

## 10. 예제

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

@media (max-width: 1023px) {
  .container {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 767px) {
  .container {
    grid-template-columns: 1fr;
  }
}
```

위 코드는 다음 의미를 가진다.

- 기본적으로는 3열 구조를 사용한다.
- 태블릿 크기에서는 2열 구조로 바꾼다.
- 모바일 크기에서는 1열 구조로 바꾼다.

즉, 같은 구조라도 화면 크기에 따라 다른 레이아웃을 적용할 수 있다.

## 11. 중요 포인트

- 반응형 웹은 다양한 화면 크기에 맞게 레이아웃이 변하는 웹이다.
- Media Query는 특정 조건에서만 CSS를 적용하는 기능이다.
- `max-width`는 해당 값 이하에서 적용된다.
- `min-width`는 해당 값 이상에서 적용된다.
- 브레이크포인트는 레이아웃이 깨지기 시작하는 지점을 기준으로 잡는다.
- 일반적으로 모바일, 태블릿, 데스크탑 구간으로 나누어 설계한다.
- 반응형 웹은 보통 모바일부터 만드는 방식이 효율적이다.
- 모든 서비스가 반응형이 필요한 것은 아니며, 사용 환경에 따라 달라진다.

## 정리

Media Query는 화면 크기나 디바이스 조건에 따라 다른 CSS를 적용할 수 있게 해 주는 기능이다.  
이 기능을 통해 하나의 코드로 모바일, 태블릿, 데스크탑에 대응하는 반응형 웹을 만들 수 있다.

반응형 웹은 단순히 화면이 줄어드는 것이 아니라, 화면 크기에 맞게 레이아웃을 다시 설계하는 것이다.  
이를 위해 `flex`, `grid`, `minmax`, `auto-fit` 같은 CSS 기능을 활용하고, 필요한 경우 Media Query를 통해 구간별 스타일을 추가 적용한다.

또한 브레이크포인트는 외워서 쓰는 숫자가 아니라, 실제로 레이아웃이 깨지는 시점을 기준으로 정해야 하며, 실무에서는 모바일부터 설계한 뒤 큰 화면으로 확장하는 방식이 많이 사용된다.
